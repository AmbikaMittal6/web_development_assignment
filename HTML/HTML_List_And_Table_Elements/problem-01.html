Admission Guide 2026

Welcome to the GLA University Admission Guide. This page provides useful information about eligibility, application steps, documents, important admission terms and the fee structure.

Application Deadline: 15 July 2026

Admission Overview

GLA University provides undergraduate and postgraduate programs in different academic fields. Students should check the requirements of their selected program before submitting an application.

Eligibility

  • 10+2 qualification from a recognized board.
  • Required subjects according to the selected program.
  • Student should satisfy the minimum eligibility criteria.
  • Valid academic documents must be submitted.

Application Process

Students can follow these steps:

  1. Visit the official GLA University website.
  2. Open the admission section.
  3. Create an applicant account.
  4. Fill in the application details.
  5. Upload the required documents.
  6. Pay the applicable application fee.
  7. Submit the completed application form.

Required Documents

  • Class 10 marksheet
  • Class 12 marksheet
  • Transfer Certificate
  • Migration Certificate
  • Passport-size photographs
  • Government identity proof
  • Category certificate, if applicable

Important Terms

Eligibility
The conditions that a student must satisfy for a course.
Merit List
A list prepared according to the qualifying performance of applicants.
Counselling
A process through which students receive admission-related guidance.
Scholarship
Financial support provided to eligible students.
Registration
The process of entering student details to begin an application.
